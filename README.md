## 🛠️ Proyectos destacados

### 🍒 Cereza Gifts — Sistema web de cotizaciones

Sistema web B2B para consultar productos promocionales, calcular precios y solicitar cotizaciones. Integra un catálogo de proveedores y herramientas administrativas para gestionar la información comercial.

- Integración de proveedores mediante API e importación de archivos Excel.
- Cálculo de precios y validación de disponibilidad desde el servidor.
- Generación de cotizaciones en PDF y presentaciones PowerPoint.
- Panel administrativo para gestionar productos, proveedores, precios y cotizaciones.
- Autenticación administrativa, control de roles y gestión de sesiones.

**Tecnologías:** React, Tailwind CSS, Node.js, Express, MySQL, PDFKit y PptxGenJS.

### 📑 [Cereza Presentaciones](https://github.com/esdrasbasurto6-afk/Cereza-Presentaciones-Descargas)

Aplicación de escritorio para Windows que transforma cotizaciones PDF de un formato específico en presentaciones PowerPoint con diseño corporativo.

- Extracción de productos desde el PDF.
- Revisión de partidas, imágenes e importes.
- Vista previa de las diapositivas antes de generar el archivo.
- Procesamiento local de documentos.
- Distribución mediante instalador y versión portable.

**Tecnologías:** Electron, JavaScript, PptxGenJS y electron-builder.

📥 [Descargar para Windows](https://github.com/esdrasbasurto6-afk/Cereza-Presentaciones-Descargas/releases)

> El repositorio público está destinado a distribuir la aplicación; el código fuente se mantiene privado.

### 🤖 [TicketFix AI](https://github.com/esdrasbasurto6-afk/ticketfix-ai)

Plataforma de soporte técnico con inteligencia artificial que clasifica tickets por categoría y prioridad, guía diagnósticos paso a paso y escala incidencias a soporte humano.

### 🎮 [La Campanita](https://github.com/esdrasbasurto6-afk/CampanitaWeb)

Plataforma web para un videojuego inspirado en la zona arqueológica de La Campana. Incluye autenticación, perfiles de usuario, contenido multimedia, modelos 3D y un panel administrativo.

### 🛒 [Ferretería ML](https://github.com/esdrasbasurto6-afk/Ferreteria_ml)

Aplicación de comercio electrónico con recomendaciones de productos, análisis de inventario, segmentación de clientes y predicción de ventas.

### 📊 [SQL Pract](https://github.com/esdrasbasurto6-afk/SQL_Pract)

Data Warehouse de ventas en MySQL con datos simulados, reportes analíticos y modelos de Machine Learning para segmentación y predicción.

### 👕 [Focopus Prints](https://github.com/esdrasbasurto6-afk/Focopus)

Plataforma de comercio electrónico de prendas personalizadas con catálogo por categorías, carrito de compras, flujo de pago y un panel administrativo para gestionar inventario y pedidos.
